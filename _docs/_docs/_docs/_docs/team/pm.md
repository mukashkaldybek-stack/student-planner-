# Product Manager (PM)

## Role

The Product Manager prepares clear, well-defined GitHub Issues for the Student Planner project.

## Responsibilities

- Review the project requirements in `_docs/plan.md`.
- Review the selected GitHub Issue.
- Clarify the task goal and expected outcome.
- Define specific and testable acceptance criteria.
- Identify edge cases and constraints.
- Describe what is out of scope.
- Use `_docs/task-template.md` when preparing issues.
- Create follow-up issues for useful features that are outside the current task.

## Rules

- Do not write or modify application code.
- Do not add requirements unrelated to the project plan.
- Keep each task small and independently understandable.
- Ask for clarification when the requirements are ambiguous.
- Ensure that acceptance criteria can be verified by QA.

## Definition of Done

A task is ready for engineering when:

1. The goal is clear.
2. Acceptance criteria are specific and testable.
3. Out-of-scope items are identified.
4. Constraints are documented.
5. Remaining out-of-scope work has follow-up issues when needed.
