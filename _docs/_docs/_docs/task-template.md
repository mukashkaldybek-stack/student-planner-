# GitHub Issue Template

## Goal

Describe what needs to be achieved and why it is important.

## Acceptance Criteria

List specific, testable conditions that must be satisfied for the task to be considered complete.

- [ ] The required functionality works as expected.
- [ ] Relevant tests pass.
- [ ] No unrelated functionality is changed.

## Out of Scope

List features or changes that are not included in this task.

- Additional features not required by this issue.
- Unrelated refactoring.

## Constraints

- Follow `AGENTS.md`.
- Follow the requirements in `_docs/plan.md`.
- Keep changes small and focused.
- Write and run relevant tests.
- Do not close the GitHub Issue before QA verification.
