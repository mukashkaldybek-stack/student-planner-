# Student Planner — Project Plan

## 1. Project Overview

Student Planner is a web application that helps students organize academic tasks, manage deadlines, and track their progress.

## 2. Problem Statement

Students may forget homework, miss assignment deadlines, and have difficulty organizing tasks across different subjects.

## 3. Goals

- Make it easy to create and manage study tasks.
- Help students keep track of deadlines.
- Organize tasks by subject.
- Show which tasks are completed and which remain unfinished.

## 4. Target Users

School students and university students who want a simple way to organize their studies.

## 5. MVP Features

### Task Management
- Create a task with a title.
- Add a deadline.
- Assign a subject.
- Edit task details.
- Delete a task.

### Task Tracking
- Display all tasks in a list.
- Mark a task as completed.
- Distinguish completed and incomplete tasks.

### Organization
- Group or identify tasks by subject.
- Show task deadlines clearly.

## 6. Out of Scope for the MVP

The first version will not include:
- AI-generated study schedules.
- Push notifications.
- User accounts and social features.
- A complex calendar system.

These features may be considered in future versions.

## 7. Acceptance Criteria

The MVP is acceptable when:
- A user can create a task with a title and deadline.
- A user can view the task list.
- A user can edit and delete tasks.
- A user can mark a task as completed.
- A task can be associated with a subject.
- The main functionality is covered by tests.

## 8. Development Principles

- Work on one GitHub Issue at a time.
- Define acceptance criteria before implementation.
- Write and run tests.
- Review each task before closing its issue.
- Keep documentation up to date.

## 9. Future Improvements

- Weekly calendar.
- Deadline reminders.
- AI-powered study planning.
