# Student Planner — Brainstorming

## 1. Initial idea

I want to build a Student Planner application that helps students organize their studies and manage their time.

## 2. Problem

Students often forget homework, miss deadlines, and struggle to organize their daily study schedule.

## 3. Target users

The main users are school students and university students who want to manage their academic tasks more effectively.

## 4. Proposed solution

Student Planner will help students:
- Add and manage homework tasks.
- Set deadlines for assignments.
- Organize tasks by subject.
- Track task completion.
- View upcoming deadlines.

## 5. MVP (Minimum Viable Product)

The first version will include:
1. Adding a task with a title and deadline.
2. Selecting a subject for each task.
3. Viewing a list of tasks.
4. Marking tasks as completed.
5. Editing and deleting tasks.

## 6. Future improvements

Possible future features include a weekly calendar, reminders, and AI-powered study planning.

## 7. Development approach

I will follow an AI-native development workflow: define the specification, create project documentation, break the work into GitHub Issues, implement tasks one at a time, and verify each task with tests.
